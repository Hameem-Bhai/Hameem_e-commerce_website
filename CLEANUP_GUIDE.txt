CLEANER GITHUB FILE LIST - SAFE PLAN

GitHub's Code page displays the repository tree above the README. README HTML
cannot restyle or collapse that surrounding file browser. Organizing root files
into folders reduces the root list; compressing image bytes does not reduce rows.

IMMEDIATE ACCESS
After adding README.md, share the repository URL with #readme appended, or a
link to README.md's rendered file view. GitHub generates heading anchors too.

SAFE FIRST CLEANUP (run from this repository's root)
1. Save your work and inspect git status.
2. The existing .gitignore already contains node_modules/ and upload_ready.zip.
   They remain listed because they were tracked earlier.
3. Stop tracking just those generated paths, keeping local copies:

   git rm -r --cached --ignore-unmatch node_modules
   git rm --cached --ignore-unmatch upload_ready.zip
   git status

4. Review staged changes. Stage README.md and docs/assets/dokan-studio.gif.
5. Commit, then pull remote updates if needed and push.

Keep package.json and package-lock.json tracked. npm ci reinstalls dependencies.
These commands do NOT remove old Git history and do NOT remediate leaked secrets.
Do not run git clean or delete source files merely to shorten the root listing.
